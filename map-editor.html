Apne ghar ka asal naqsha banao — kamray, sehan aur main gate waisay rakho jaisay asal mein hain. Dashboard par jo map abhi dikhta hai (Kamra 1, Kamra 2, Sehan, Main Gate) wo aik ghar ka hai — har ghar ka naqsha alag hota hai.

Kaise banayen (3 steps)

  1. Ghar ka naam likho — masalan "Mera Ghar".
  2. Zone add karo — naam likho (masalan "Bara Kamra"), type chuno, phir neeche canvas par tap karo jahan zone ho, ya x / y / size number likho. "Zone Add Karo" dabao. Aik aik kar ke saare kamray, sehan aur gate add karo.
  3. "Map Save Karo" dabao — map aap ke browser mein save ho jata hai. Phir "Dashboard par Dekho" se dekho — dashboard ab aap ka map dikhayega.
