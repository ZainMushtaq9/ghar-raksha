Kaise kaam karta hai (5 steps)

  1. Sensor lagte hain — gate, sehan aur kamron mein. Radar banda aate hi pakar leta hai, chahe andhera ho ya munh dhaka ho.
  2. ESP32 dimaagh hai — aik chhota board jo saare sensors se jura hota hai aur WiFi se connected hota hai.
  3. Raat ko system "Armed" hota hai — dashboard ya phone se on karo. Din mein ghar walon ki aamad-o-raft par kuch nahi hota.
  4. Banda aate hi — siren bajta hai, light on hoti hai, aur phone par Telegram alert aata hai, usi waqt.
  5. Dashboard par activity nazar aati hai — ghar ka map dikhta hai, kis zone mein banda hai, kab aaya, kab gaya. Website se system ko Arm/Disarm bhi kar sakte ho — website sirf dikhati nahi, jawab bhi deti hai.

Sachi hadain (pehle se pata hon)

  • Aik sensor aik kamra/zone dekhta hai — har zone ko apna sensor chahiye.
  • Radar moti eent/concrete deewar ke peeche reliable nahi hai.
  • PIR ko seedha nazar chahiye; pankha, heater ya paalto janwar ghalat alarm de sakte hain.
  • Bijli gayi to system band — router par UPS aur ESP32 par power bank rakho. WiFi/internet band ho to Telegram alert ruk jata hai (WiFi wapas aate hi chala jata hai) — siren aur light phir bhi local bajte hain.
  • WiFi CSI (video wali technology) asal hai lekin research level ki hai — Phase 2 hai, main system ka hissa nahi.
  • Koi system 100% nahi hota. Ye system pakarne aur foran alert ka waqt deta hai — mazboot darwaze aur CCTV (saboot ke liye) sath rakho.

Frequency se napna — WiFi CSI (Phase 2, tajurba)

Ghar ka WiFi 2.4 GHz ki frequency par signal bhejta hai. Jab kamray mein koi banda chalta hai, to us ka jism is signal ko halka sa bigaar deta hai — signal ki frequency/amplitude hil jati hai. Doosra ESP32 is signal ko sun kar nap sakta hai ke kamray mein koi hai ya nahi. Matlab: jo network pehle se maujood hai, usi ki frequency se banda napna — koi SIM, koi mobile data, koi naya network nahi chahiye. Router hi sender ban sakta hai, ya do ESP32 (aik bhejta hai, aik sunta hai).

Kya chahiye: extra ESP32 x1 (~Rs 1,200), ESP-IDF framework, aur ghar ke kamray mein calibration (pehle "khali kamra" phir "banda maujood" dikha kar sikhana).

Sachai: ye EXPERIMENTAL hai — abhi bana nahi, baghair hardware ke verify nahi hua. Phase 1 (PIR / radar / door sensor) woh rasta hai jo abhi bharose se kaam karta hai; CSI us ke baad ka tajurba hai. Agar Phase 2 chal gaya to bina sensor ke bhi maujoodgi ka pata chalega, aur aage chal kar yehi tareeqa zyada zones ya public use ke liye barhaya ja sakta hai.

Aksar pooche gaye sawal (FAQ)

Ghar Raksha banane mein kitna kharcha aata hai?

Starter (1 zone) ~Rs 5,500, Full (3 zones + LD2410) ~Rs 8,000–8,500, aur Full + power backup ~Rs 10,000–11,000 (andaza). System WiFi-only hai — koi GSM ya SIM nahi chahiye. Qeematein 25 Nov 2026 ko Pakistan ki dukaanon se check ki hui hain. LD2410 ki qeemat andaza hai, verify nahi hui.

Kya ye system CCTV ke baghair kaam karta hai?

Ji. System camera par nahi, sensors par chalta hai — PIR, radar aur mmWave sensor harkat pakarte hain, chehre ki zaroorat nahi. CCTV sirf saboot ke liye sath rakhna behtar hai.

Kaunse sensors lagte hain?

PIR HC-SR501, RCWL-0516 microwave radar, HLK-LD2410 mmWave sensor aur MC-38 magnetic door sensor. Aik hi ESP32 chaaron zones chala leta hai.

Mahinaana kharcha kitna hai?

Rs 0. Telegram alert ghar ke WiFi se free hai, koi subscription nahi, koi SIM ya mobile data nahi chahiye.

Dashboard ka DEMO MODE kya hai?

DEMO MODE mein dashboard nakli (simulated) data dikhata hai — koi asal sensor nahi hota. LIVE MODE mein ye ESP32 se jor kar asal zones, arm/disarm aur alerts dikhata hai.

Firmware kahan se download karoon?

Downloads page par source code (home_guard.ino) aur tayyar compiled firmware (.bin) dono hain. Source code recommended hai, kyun ke us mein apna WiFi naam aur password bharna hota hai.
