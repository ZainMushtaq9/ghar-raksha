2. Tayyar firmware (.bin) — seedha flash karo

Arduino IDE use nahi karna to tayyar files ko esptool se seedha ESP32 par flash kar do. Pehle esptool install karo:

pip install esptool

Phir ye 4 files download karo aur aik command chalao (Windows par COM3 ki jagah apna port likho, masalan COM4; Linux/Mac par /dev/ttyUSB0):

firmware.bin bootloader.bin partitions.bin 

esptool.py --chip esp32 --port COM3 --baud 460800 write_flash -z 0x1000 bootloader.bin 0x8000 partitions.bin 0x10000 firmware.bin
Zaroori: teenon files aik sath flash karo — sirf firmware.bin akela kaam nahi karega, kyun ke ESP32 ko bootloader aur partition table bhi chahiye hoti hai. Flash ke baad ESP32 ko USB se nikaal kar dobara lagao, phir Serial Monitor (115200 baud) mein WiFi ka IP dekho.

WiFi naam/password .bin mein nahi badla ja sakta — .bin mein APNE_WIFI_KA_NAAM / APNA_WIFI_PASSWORD placeholder hai. Apna WiFi bharna ho to source code (option 1) use karo. Telegram alert ke liye bhi source code chahiye (token + chat ID code mein bharna parta hai).
