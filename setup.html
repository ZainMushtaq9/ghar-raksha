Setup Guide — step by step

Pehle poora guide parh lo, phir kaam shuru karo. Samaaan ki list Shopping List par hai.

1. Samaan (pehle se khareeda hua)

  • ESP32 DevKit V1 (1x) — aik hi board 4 zones chala leta hai
  • PIR HC-SR501 (Gate, Sehan, Kamra 1, Kamra 2 ke liye)
  • RCWL-0516 (Sehan, Kamra 1 ke liye — optional)
  • HLK-LD2410 (Sehan ke liye — optional, behtareen hai)
  • MC-38 magnetic door sensor (Gate, Kamra 1, Kamra 2 ke liye)
  • 12V siren + relay module (2-channel)
  • Chhota buzzer (5V active)
  • 12V 2.5A adapter (ESP32 ko 5V USB se bhi chala sakte ho)
  • Jumper wires, breadboard ya vero board, plastic box

2. Pin Connection Table (ESP32 pin → sensor pin)

Ye table firmware (home_guard.ino) se bilkul match karti hai. Agar pin badlo to code mein bhi badlo. Verify kiya hua: 14/14 pins match.

3. Assembly ka order

  1. Pehle ESP32 ko USB se laptop se joro, code upload karo (Step 4).
  2. Phir aik zone joro — sirf Sehan ka PIR. Test karo.
  3. Test pass ho to baaki PIR joro, aik aik kar ke test karte jao.
  4. Phir door sensor, phir RCWL, phir LD2410.
  5. Aakhir mein siren + relay joro (siren test karte waqt kaan band rakho — bohat tez hota hai).
  6. Sab kuch plastic box mein band karo, taarein tape/cable tie se saaf rakho.

4. Code upload karna (Arduino IDE)

  1. Arduino IDE install karo (arduino.cc se, free hai).
  2. IDE mein: File → Preferences → "Additional Boards Manager URLs" mein ye daalo: https://espressif.github.io/arduino-esp32/package_esp32_index.json (Ye official Espressif ka link hai.)
  3. Tools → Board → Boards Manager → "esp32" search kar ke Espressif ka board package install karo.
  4. Tools → Board → "ESP32 Dev Module" select karo. Port apni USB wali select karo.
  5. home_guard.ino file kholo.
  6. Upar CONFIG mein apna WiFi naam + password bharo. Telegram chahiye to token + chat ID bharo (tareeqa code ke comments mein likha hai). Jo sensor nahi khareeda, us ka #define band kar do (line ke shuru mein //).
  7. Upload dabao. Upload ke doran agar "Connecting..." par atak jaye to ESP32 par BOOT button daba kar rakho, phir upload karo.
  8. Upload ke baad: Tools → Serial Monitor kholo (115200 baud). Wahan WiFi ka IP address nazar aayega — us ko note kar lo, dashboard ko yehi IP chahiye.

Code pehle se compile-verify hai (PlatformIO: RAM 14.7%, Flash 77.0%). Agar Arduino IDE use nahi karna to tayyar .bin file ko seedha flash kar sakte ho — tareeqa Downloads par hai.

5. Dashboard ko ESP32 se jorna

  1. Laptop/phone aur ESP32 aik hi WiFi par hon.
  2. Dashboard kholo.
  3. LIVE MODE dabao.
  4. ESP32 ka IP likho (Serial Monitor wala, masalan 192.168.1.100) aur Lagao dabao.
  5. Agar "ESP32 connect nahi" aaye to check karo: IP theek hai? ESP32 on hai? Dono aik hi WiFi par hain? Router ne IP badal to nahi diya (dobara Serial Monitor dekho)?

Dashboard har 1 second mein ESP32 se /status mangta hai. Arm/Disarm dabane par dashboard ESP32 ko /arm ya /disarm bhejta hai — website se system ko control bhi kar sakte ho, sirf dekh nahi sakte.

6. Har zone ka test

  1. Dashboard LIVE mode mein, system DISARMED rakho (siren na baje).
  2. Aik aik kar ke har zone mein jao — dashboard par us zone mein "BANDA!" aana chahiye.
  3. Darwaza kholo — "Darwaza khula" aana chahiye.
  4. Phir ARM karo aur dobara zone mein jao — siren bajna chahiye, light jalni chahiye, Telegram alert aana chahiye (agar token bhara hai).
  5. Test ke baad DISARM kar do.

7. Raat ko arm karna (roz ka tareeqa)

  • Sone se pehle dashboard kholo aur ARM karo (ya browser mein http://<ESP32-IP>/arm kholo).
  • Subah uth kar DISARM karo, warna ghar walon ki movement par siren bajega.
  • Ghar se bahar jate waqt bhi ARM karo.

8. Sachi hadain (honest limits — zaroor parho)

  • Ek sensor = ek zone. Ek PIR poora ghar nahi dekh sakta. Har kamray ko apna sensor chahiye.
  • Radar moti deewar ke peeche bharosa nahi karta. Brick/concrete deewar ke us paar banda dekhna mushkil hai — is liye sensor usi kamray mein lagao jis ki hifazat karni hai. TikTok video jaisa "deewar ke paar tracking" asal mein aisa nahi hota.
  • PIR ko seedha nazar (line of sight) chahiye. Almari ya parde ke peeche banda PIR ko nazar nahi aata.
  • Sensor ko pankhe/heater se door rakho. Pankha, heater, AC ki hawa aur paalto janwar (kutta/billi) ghalat alarm de sakte hain. PIR ko janwar ki oonchai se upar lagao.
  • 100% detection ka wada koi nahi kar sakta. Ye system chor ko mushkil banata hai aur foran khabar deta hai — laikin koi bhi system akela kaafi nahi. Mazboot darwaze, achi kundiyan aur CCTV (saboot ke liye) sath rakho.
  • Load-shedding: Bijli gayi to ESP32 + sensors band ho jayenge, aur Telegram alert ke liye WiFi router ka on hona bhi zaroori hai. Hal: router par chhota UPS lagao (wohi UPS jo aksar ghar mein WiFi ke liye hota hai) aur ESP32 ko power bank se chalao. WiFi/internet band ho to Telegram alert ruk jata hai — WiFi wapas aate hi chala jata hai; siren aur light phir bhi local bajte hain. (System WiFi-only hai — koi GSM/SIM nahi hai.)
